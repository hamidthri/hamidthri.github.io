The moving background on the home page is not decoration for its own sake. It's a small,
real-time **navigation agent**: it senses obstacles with simulated LiDAR, steers toward a goal
(your cursor), avoids what's in the way, and draws the path it planned. It's the same loop my
research is about — perception, policy, control — rendered as something you can play with.

## Relevant, not just pretty

- The **LiDAR beams** sweep and light up obstacles they hit.
- The **amber ribbon** is the agent's recent path — literal path planning.
- The drifting **point cloud** overhead nods to my 3D-perception work
  ([DGCNN / PointNet](/projects/3d-scene-understanding)).
- The **telemetry** in the corner reports the agent's position and speed.

## Graceful by design

A flashy 3D scene is worthless if it makes the page slow or unusable. So the hero ships with a
**capability ladder**:

1. Capable desktop + motion allowed → the full Three.js scene.
2. No WebGL, or reduced-motion preference → a lightweight 2D canvas version.
3. Low-power or mobile → the 2D version at reduced quality.

The 3D code is lazy-loaded only when it's actually going to run, so a phone or a
reduced-motion visitor never downloads it. The rest of the site is plain, fast, static HTML
from [Astro](https://astro.build) — multi-page, easy to maintain, and quick to read.
