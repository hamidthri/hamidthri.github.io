A small, sharp developer tool: talk to your coding agent without giving up privacy. The
extension captures audio, transcribes it **locally** with whisper.cpp, and forwards the text
over **MCP** to whichever agent you use.

## Design

- **Local-first.** Audio is transcribed on-device — nothing is uploaded, no API keys needed.
- **Agent-agnostic.** Works with Claude Code, Codex, Copilot and anything that speaks MCP.
- **TypeScript VS Code extension** — a clean integration into the editor workflow.

Built while working day-to-day with coding agents — scratching a real itch in the tooling
around them.
