A production-grade **OCR inference server** built for throughput. The full pipeline —
detection, recognition, post-processing — runs on the GPU with TensorRT FP16.

## Headline

- **268 img/s @ 90.2 F1 on FUNSD** (RTX 5090) — roughly **50× faster** than PaddleOCR's Python
  baseline (~5.1 img/s).
- **C++ / CUDA / TensorRT FP16** with **PP-OCRv5** weights.
- **HTTP + gRPC** serving and **Prometheus** metrics for real deployment.

This is the kind of real-time OCR / GPU-inference systems work I do day-to-day as an Applied
AI Engineer at amitego.
