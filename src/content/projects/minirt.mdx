Computer graphics from first principles. **MiniRT** implements a ray tracer in pure C, with no
rendering library doing the heavy lifting.

## Built from scratch

- **Ray–object intersection** for spheres, planes and cylinders.
- **Phong shading** with diffuse and specular terms, hard shadows and material reflections.
- **`.rt` scene parser** — describe a scene in a text file and render it.

The dragon and wolf renders are direct output. This project is the low-level, mathematical
counterweight to my ML work — and the renders double as artwork across the site.
